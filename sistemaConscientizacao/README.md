
# 🛡️ ConectaSeguro

### Sistema de conscientização sobre segurança digital para jovens na Internet

O **ConectaSeguro** é um site educativo desenvolvido com o objetivo de conscientizar os jovens sobre a importância da segurança digital e do uso responsável da internet.

A plataforma apresenta conteúdos informativos, dicas de proteção e um quiz interativo para ajudar os usuários a reconhecer ameaças digitais e adotar hábitos mais seguros no ambiente virtual.

## 🎯 Objetivo

Promover a conscientização sobre segurança digital entre os jovens, apresentando informações de maneira simples, acessível e interativa.

## 🚀 Funcionalidades

- **Conteúdos educativos:** informações sobre phishing, senhas seguras e proteção de dados pessoais.
- **Dicas de segurança:** recomendações para navegar na internet com mais segurança.
- **Quiz interativo:** perguntas para testar os conhecimentos adquiridos.
- **Feedback das respostas:** explicações sobre as alternativas corretas e incorretas.
- **Resultado final:** apresentação da pontuação do usuário ao concluir o quiz.
- **Design responsivo:** adaptação para computadores e dispositivos móveis.

## 🛠️ Tecnologias utilizadas

## 💻 Como executar o projeto

É necessário ter o Node.js instalado.

1. Clone o repositório:

```bash
git clone URL_DO_REPOSITORIO
```

2. Entre na pasta do projeto:

```bash
cd NOME_DA_PASTA
```

3. Instale as dependências:

```bash
npm install
```

4. Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

5. Acesse o endereço apresentado no terminal, geralmente:

```text
http://localhost:5173
```
